# BLUE_BLUE 是什么
BLUE 是一个“图纸”工具：你先创建图纸（输入、选区、画布、映射、Result 命名），再在流程里使用图纸，把皮肤图合成、拆组、改名、导出。图纸可以保存、打开、分享；流程只是决定这次怎么用图纸。
BLUE = Blueprint Layout & Usage Engine（图纸工坊）。当前版本 3.0.4beta。
30 秒上手
1. 主界面点「源文件」右边的 …，选一张皮肤 PNG。
2. 在「流程」下拉里选一条流程（第一次用就用「默认流程」）。
3. 点「启动流程」。
4. 遇到暂停：询问模式填名字，提示模式点继续；有图的暂停会把图放到 临时/ 里，可以先改再继续（见下面「暂停修改图片」）。
5. 跑完去 程序目录/导出/<文件夹名>/ 拿图。
主界面
· 源文件：选皮肤 PNG。选了之后，流程里「源文件」节点留空也会优先用它。
· 编辑流程：打开流程编辑器。
· 启动流程：按当前流程跑一遍。
· 流程下拉 + 右边的 +：切换 / 新建流程。
· 流程卡片下面是「蓝图编辑器」和「资源管理器」。
· 右上角是「关于」「教学文档」「设置」。默认浅色主题，设置里可切深色。
流程编辑器
曲线连接、带类型端口的节点图。只有从起点能连到的节点才会执行，画布外孤立的节点不会弹窗、不会导出。
鼠标与快捷键
· 中键拖动 = 平移整个网格。
· 左键单击 = 选中；左键拖空白 = 框选多选。
· 左键拖节点 = 移动；多选时拖任意一个会整组移动。
· Ctrl + 左键 = 加选 / 取消选中；Delete = 删除选中的节点。
· 滚轮 = 缩放；右键空白 = 添加节点的菜单；右键节点 = 跳过 / 删除。
· Alt + 左键点端口圆点 = 删掉这个端口上的线。
节点
源文件     → 整张皮肤原图
暂停       → 继续 / 回答；有图时把当前图写到 临时/ 供修改
蓝图       → 每个有效 Result 一个输出 + 一个图组输出
Make 合并  → 多个输入（1~16）合成一个图组
Break 拆分 → 一个图组拆成多张图，输出数量自动
放大       → 像素放大 N 倍
重命名     → 按模板改名字，可接自己的 Text
导出       → 按文件夹名 + 图片自己的名字写文件
蓝图节点的高度会随 Result 数量变化；Make / Break 的高度随端口数量变化。
「跳过」对普通节点是透传；Make / Break 是结构节点，勾了跳过仍会执行。
Make / Break 怎么用
· Make：参数里设「输入数量」（1~16），节点会长出 图像1…图像N。每个输入可以接一张图，也可以接一个组；没连的输入直接跳过，不会拿源文件顶替。
· Break：接一个图组，输出点数量自动跟着上游算——蓝图图组按 Result 数、Make 按实际连上的图片数、单张图就是 1 个。
· 典型用法一：蓝图 3 个 Result，把 result1 + result2 用 Make 合成组再导出。
· 典型用法二：蓝图图组接到 Break，拆开后每张图分别接重命名 / 放大 / 导出。
· Break 的输出数会在连线、打开流程、刷新蓝图端口和运行前重新同步；上游变少时多出来的线会被清掉。最多 64 个输出点。
暂停修改图片
暂停节点接了图像输入后，暂停时会把当前图（一张或一个图组）写到：
临时/暂停_<流程名>_<节点号>_<时间>/01_名字.png
· 节点参数里勾「自动打开」，暂停时会自动弹出这个文件夹；对话框里也有「打开文件夹」按钮。
· 用画图 / PS 改这些 PNG，改完点「继续」，程序会按文件名顺序读回来，后面的节点用的就是改过的图。
· 不勾「自动打开」也会落盘，只是不弹文件夹。
· 没有接图像输入的暂停（纯文字询问）不会建文件夹。
· 临时/ 里的文件不会自动删，确认没用了可以手动清。
暂停的 Text
暂停（询问模式）的「回答」是一个文本输出，接给谁，谁就能用 {Text}。重命名、蓝图、导出各有自己的 Text 输入：接哪个暂停，就用哪一次的回答；不接就是空，不会去拿别的暂停的回答。
暂停 A「回答」→ 重命名 1（{Text}_头部）
暂停 B「回答」→ 重命名 2（{Text}_眼睛）
导出节点
· 「文件夹名」输入 = 导出的文件夹名。不接就用皮肤文件名。
· 图片文件名用图片自己的名字（蓝图 Result 的命名模板）。
· 「命名模式」留空即可；写了会覆盖图片自己的名字。
· 同名默认跳过，勾「同名覆盖」才会覆盖。
蓝图编辑器
左边是节点区：输入（示例图）→ 画布 → Result；矩形节点也连到画布。右边上面是输入与选区，下面是画布 / 矩形 / Result 的属性。
输入与选区
· 输入是一张示例图，只用于设计时拉框参照，运行时不参与。
· 在示例图上按住拖 = 新建选区；按住已有选区拖动；拖右下角改大小。
· 选区坐标吸附到整数像素；自动命名 选区1、选区2……，可以改名，也能直接输入 X / Y / W / H。
· 顶部「放大」把示例图铺满屏幕来拉框，滚轮缩放、中键拖动，Esc 关闭。
画布与映射
· 画布尺寸由你输入，单位是像素。
· 「素材」下拉里会列出：连到画布上的输入图选区 + 连到画布上的矩形节点里的矩形。
· 「添加映射」把素材贴到 (0,0)，然后在画布预览里拖动摆位置；X / Y 也能手输。
· 映射列表的顺序就是叠放顺序（后面的盖住前面的），可以拖动排序或用 ↑ ↓。
· 画布区右上角「放大编辑」把画布铺满屏幕，方便摆位。
矩形节点
· 右键空白 → 添加：矩形。节点里可以放多个矩形，每个有名称、宽、高、颜色。
· 矩形节点用橙色端口连到画布，之后就能在画布的「素材」里选到它。
· 矩形可以当底色、边框、色块；映射顺序和选区共用。
Result
· 一个 Result 只接一个画布；N 个有效 Result = 流程里 N 个输出点 + 一个图组。
· 命名模板写在 Result 上，导出 / 重命名时按这个模板起名。
Result 命名变量
公用（整次运行 / 整个蓝图节点）：
· Skin：皮肤文件名；Time：202610310303；Date：20261031。
· Text：这个蓝图节点「字符」输入的文字；同一个蓝图节点下所有 Result 共用。
私有（每个 Result 自己算）：
· L / W：这个 Result 对应画布的像素宽 / 高；要厘米就自己乘，例如 {L*3.75}cm。
· Canvas / Name：这个 Result 接的画布名；Result：Result 名；Index：第几个 Result（从 1 开始）。
写法：
{Skin}{"_"}{L}{"x"}{W}
{Skin}_{Result}_{L}x{W}
{Text}{"_"}{W*6.1875}{"cm"}
· 可以用 + - * / %、括号，以及 round / int / floor / ceil / abs / str / upper / lower / max / min。
· 字符串用 "cm" 或中文引号 “cm”；{_} 这种纯符号块直接当字面量。
· 小写别名 {text}、{skin}、{canvas}、{result}、{index} 也能用；中文别名 {长}、{宽}、{时间}、{文字} 也可以。
全屏编辑
示例图和画布都能全屏编辑：左边大图，右边保留列表、坐标、宽高、颜色等属性。滚轮缩放、中键拖动画面，Esc 关闭后自动同步回蓝图。
导出规则
· 导出节点的「文件夹名」输入 = 文件夹；不接 = 皮肤文件名。
· 设了「导出根目录」：<根目录>/<文件夹名>/；没设就是 程序目录/导出/<文件夹名>/。
· 图片文件名用图片自己的 Result 命名；同名时第二张会加它来自的 Result 名做前缀。
· 命名模式留空即可；写了 {Result}、{L}、{Text} 等可以临时覆盖文件名。
· 设置里勾「填充颜色」会把透明区域压到所选背景色；默认保留透明。
分享与打开
· 流程编辑器、蓝图编辑器都有「打开…」：选别人分享的 JSON，导入到 workflows/ 或 blueprints/ 并直接打开；重名会让你改名。
· 「目录」直接打开对应文件夹，方便拿文件分享。
· 蓝图 JSON 里的示例图是可选的；分享时没带示例图也能正常运行，只是设计时没有参照图。
· 分享流程时，记得把流程里用到的蓝图 JSON 也一起发。
设置
· 主题：浅色 / 深色。
· 填充颜色：导出时把透明区域压到指定颜色；默认不填充，保留透明。
· 设置保存在 skin_head_settings.json。
常见问题
暂停问了两次 / 孤立节点也执行？
只有从起点连得到的节点会执行；画布外孤立的暂停不会执行。如果确实有两个暂停连在线上，就会各问一次。
暂停后找不到图片文件？
暂停本身不直接写 导出/；有图输入的暂停会把图写到 临时/暂停_…/，点继续后流程继续往导出走，导出节点执行后才会在 导出/ 下出现文件。
导出没有文件？
检查：导出节点是否连在暂停后面、是否点了继续（不是取消）、导出节点是否报错、命名是否被同名跳过。
文件名后面多了 result2_？
两个 Result 的命名模板撞名了，程序给第二张加了它来自的 Result 名前缀。把模板改成带 {Result} 或 {Index} 就能区分。
蓝图节点没有输出点？
蓝图里需要至少一个有效 Result（接了画布、有映射），然后打开流程或点「刷新蓝图端口」。
Break 的输出数量和想的不一样？
Break 跟着上游实际会带几张图算：蓝图图组按 Result 数、Make 按实际连上的图片数、单张图 = 1。改完蓝图或 Make 后点「刷新蓝图端口」，或重新打开流程。
旧流程重命名里的 {Text} 变空了？
重命名的 Text 现在只取接在它自己 Text 口上的暂停回答；把对应暂停的「回答」连到重命名的 Text 口即可。
临时/ 和 导出/ 在哪？
都在程序目录（exe 所在目录，或脚本所在目录）。
